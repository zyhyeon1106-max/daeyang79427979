# 📚 대양초등학교 7942 학급 독서 미션 웹 애플리케이션

**대양초등학교 독서 행사 주간**을 위한 **「7942 학급 독서 미션」** 웹 애플리케이션입니다.  
학급 학생들이 2주 동안 함께 책을 읽고, 학급 단위로 목표를 달성할 수 있도록 돕습니다.

---

## 🌟 주요 행사 개념

- **행사 이름**: 대양초등학교 독서 행사 주간 「7942 학급 독서 미션」 (7942 = 친구사이! 다 함께 완주하는 2주간의 독서)
- **기간**: 2주간
- **미션 1. 79시간 42분 읽기**
  - 학급 학생들이 2주 동안 읽은 시간을 분 단위로 누적 합산하여 **총 4,782분(79시간 42분)** 달성 목표
  - **시각화**: 지혜의 책 탑(Book Stack Visualizer) — 알록달록한 책 층이 차곡차곡 쌓이며 마스코트가 함께 상승
  - **입력 방식**: 책 제목과 함께 분(min) 단위 직접 입력 또는 내장 **독서 타이머**로 측정 후 기록
- **미션 2. 7,942쪽 독서 마라톤**
  - 학급 학생들이 2주 동안 읽은 책의 쪽수를 모아 **총 7,942쪽** 완주 목표
  - **시각화**: 독서 마라톤 트랙(Reading Marathon) — 달리는 어린이 러너 캐릭터가 결승선(7,942쪽)을 향해 전진
- **🏆 7942 더블 미션 성공!**: 두 미션을 모두 달성한 학급에게 주어지는 최고 명예의 골드 배지 및 축하 애니메이션

## Render에서 데이터가 삭제 후 다시 살아나거나 새 기록이 사라지는 경우
이 앱은 SQLite를 사용합니다. Render의 기본 파일시스템은 재시작/재배포 때 초기화될 수 있으므로, 운영 환경에서는 **Persistent Disk**가 필요합니다.

1. Render 서비스에 Persistent Disk를 추가합니다.
2. Mount Path를 `/var/data`로 지정합니다.
3. 환경 변수 `DATA_DIR=/var/data`를 추가합니다. (또는 `DB_PATH=/var/data/reading_mission.db`)
4. 다시 배포합니다.

이 버전의 저장소에는 테스트용 `reading_mission.db`를 포함하지 않습니다. 따라서 새 Persistent Disk에서 시작하면 과거 테스트 학급 없이 빈 데이터베이스로 시작하고, 이후 생성/삭제되는 데이터가 디스크에 누적됩니다.
